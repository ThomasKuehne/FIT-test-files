# FIT test files

This is a corpus of Flexible and Interoperable Data Transfer ([FIT](https://developer.garmin.com/fit/overview/)) files to support interoperability testing of FIT file decoding, parsing and visualization.

FIT files are used by - among others - [COROS](https://coros.com/), [Garmin](https://www.garmin.com/), [Suunto](https://www.suunto.com/), [Zwift](https://www.zwift.com/) and [Wahoo](https://wahoofitness.com/) for sharing health, fitness and sport data.
